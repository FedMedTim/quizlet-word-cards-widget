# Карточки слов — виджет Android с синхронизацией из Quizlet

Виджет на главный экран: слово из набора Quizlet, тап переворачивает карточку и
показывает перевод. Два размера — 2×2 и 4×2, по макету Modernist.

## Установка

**[Скачать последнюю версию](https://github.com/FedMedTim/quizlet-word-cards-widget/releases/latest/download/wordcards.apk)**
— ссылка всегда ведёт на свежий релиз, открывайте её прямо с телефона.

1. Откройте скачанный файл. Android спросит разрешение на установку из этого
   источника — дайте его.
2. Запустите «Карточки слов», войдите в Quizlet и вставьте ссылку на набор.
3. Зажмите свободное место на рабочем столе → «Виджеты» → «Карточки слов»,
   перетащите размер 2×2 или 4×2.

Сборки подписаны постоянным ключом, поэтому новые версии ставятся поверх старых
без удаления и без потери настроек.

## Как устроен доступ к Quizlet

Публичного API у Quizlet нет с 2021 года, а прямой HTTP-запрос к сайту
возвращает 403: там стоит защита от ботов, которая смотрит на TLS-отпечаток и
заголовки клиента. Проверено — обычный клиент не проходит.

Поэтому данные берутся так:

1. Пользователь один раз входит в Quizlet в `WebView` на настоящей странице
   `quizlet.com/login`. Пароль приложение не видит и не хранит — остаётся только
   сессионная кука в системном `CookieManager`.
2. Фоновая синхронизация поднимает `WebView` без окна, открывает лёгкую страницу
   на домене `quizlet.com` и выполняет там `fetch()` к внутреннему эндпоинту
   `webapi/3.4/studiable-item-documents`. Запрос идёт из настоящего браузера с
   настоящими куками, поэтому проходит.
3. JSON возвращается в Kotlin через `@JavascriptInterface`-мост, разбирается и
   складывается в Room. Виджет всегда рисует из базы, поэтому неудачная
   синхронизация не оставляет пустой экран.

Внутренний API не документирован, и обёртка ответа у него менялась. Парсер это
учитывает: он не ходит по фиксированному пути, а обходит JSON целиком и
подбирает объекты по признаку — карточка это объект с массивом `cardSides`.
Смена обёртки такой разбор переживёт.

**Ограничение, о котором стоит знать:** это внутренний интерфейс сайта, а не
разрешённый способ интеграции. Он может измениться без предупреждения, и такое
использование не согласовано с условиями Quizlet. Для личного аккаунта и своих
наборов это работает, но гарантий стабильности никто не даёт.

## Структура

```
app/src/main/java/com/wordcards/widget/
  data/           Room: наборы, карточки, отметки «выучено»; настройки
  quizlet/        WebView-клиент, устойчивый парсер, репозиторий
  sync/           WorkManager: периодическая и разовая синхронизация
  widget/         Glance-виджеты 2×2 и 4×2, действия по тапам
  ui/             Экран входа и привязки набора
```

## Взаимодействие

| Жест | 2×2 | 4×2 |
|---|---|---|
| Тап по телу карточки | перевернуть | перевернуть |
| Тап по плашке-заголовку | следующее слово | — |
| Тап по красной стрелке | — | следующее слово |
| Тап по значку динамика | озвучить | озвучить |

На 2×2 стрелки в макете нет — места не хватает, поэтому листание повешено на
плашку-заголовок.

## Прогресс и «выучено»

Полоса прогресса считает карточки, которые открывали переворотом. Прогресс
обучения из самого Quizlet не тянется: соответствующий внутренний эндпоинт не
проверен, и выдавать локальный счётчик за данные аккаунта было бы неверно.
Отметки хранятся локально и переживают синхронизацию — при обновлении набора
они переносятся по id карточки.

## Озвучка

Используется системный TTS-движок Android. У Quizlet есть свои `ttsUrl`, они
сохраняются в базе, но живут за той же защитой, что и API, — проигрыватель
получил бы 403.

## Сборка

Нужны JDK 17 и Android SDK (compileSdk 34).

```bash
./gradlew assembleDebug
```

APK окажется в `app/build/outputs/apk/debug/app-debug.apk`.
